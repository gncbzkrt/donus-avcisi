# TradingView veri katmanı

Bu sürüm TradingView WebSocket protokolünü kullanarak BIST günlük OHLCV verisi almaya çalışır. BIST sembolleri `BIST:SEMBOL` biçimindedir. Ücretsiz/kimliksiz TradingView erişimi gecikmeli olabilir; gerçek zamanlı BIST verisi için TradingView hesap ve ilgili piyasa verisi koşulları geçerlidir.

Protokol yaklaşımı, Apache-2.0 lisanslı açık kaynak `borsapy` projesinin yayımladığı TradingView sağlayıcı uygulamasından esinlenmiştir. Proje: https://github.com/saidsurucu/borsapy

Bu uygulama kişisel kullanım içindir.
